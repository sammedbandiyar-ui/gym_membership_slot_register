SOFTWARE
Python 3.12 recommended (tested); Python 3.10+ with SQLite 3.38+ and JSON support.
A browser and terminal. Internet is only needed once to install Flask.
No Node, React, external API, cloud service or JavaScript dependency.

1. EXTRACT THE ZIP and open a terminal inside gym_membership_slot_register.

2. WINDOWS COMMAND PROMPT (cmd.exe)
   py -3 -m venv .venv
   .venv\Scripts\activate.bat
   python -m pip install -r requirements.txt
   python app.py --init-db
   python tests.py
   python app.py

   WINDOWS POWERSHELL (activation not required)
   py -3 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe app.py --init-db
   .\.venv\Scripts\python.exe tests.py
   .\.venv\Scripts\python.exe app.py

   macOS / LINUX
   python3 -m venv .venv
   source .venv/bin/activate
   python -m pip install -r requirements.txt
   python app.py --init-db
   python tests.py
   python app.py

3. OPEN http://127.0.0.1:5000
   Stop the server with Ctrl+C. Restart with: python app.py
   Do NOT initialize again on every start. Initialization refuses to overwrite data.
   If port 5000 is busy: python app.py --port 5001
   Then open http://127.0.0.1:5001
