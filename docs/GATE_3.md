   active; R05 Membership valid through slot; R06 No hold; R09 Capacity available. Every name and
   message appears on screen and persists in booking.reasons. See blocked_decision.html and
   `test_all_reasons_stored_and_shown`.

   attempt blocks. Repeating `aarav` shows both capacity and duplicate failures.
